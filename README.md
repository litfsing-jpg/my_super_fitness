# Фитнес-платформа: шаблон ученика

**Начни с [пошаговой инструкции установки](START_HERE.md).** В этой папке весь комплект; чистый архив для передачи находится в `dist/`.

Один кабинет для самостоятельного сайта и Telegram Mini App. У каждой установки свои бренд, Supabase, бот и платежи. Данные и инфраструктура автора сюда не включены.

## Посмотреть

Нужен Node.js 22 или новее.

```sh
npm ci
npm run demo
```

Открой http://127.0.0.1:4211. Это отдельная локальная демонстрация с вымышленными аккаунтами. Она не подключается к базе, боту или оплате. Для другого порта: `npm run demo -- 4212`.

В комплекте анкета, план дня, создание и выполнение своей тренировки, подходы, дневник еды и воды, прогресс, два рецепта с послойной анимацией, поиск и избранное. Три коротких MP4 показывают интерфейс плеера; они явно помечены как демонстрация и не заменяют уроки тренера.

## Своя Установка

```sh
npm run setup -- --mode hybrid --origin https://your-domain.example
```

Команда создаёт `.env.local` с пустыми настройками, ничего не отправляет в сеть и не перезаписывает существующий файл. Следуй [инструкции установки](docs/SETUP.md). `npm start` без настроек показывает закрытый экран настройки, а не бесплатный доступ.

## Команды Проверки

`npm test` проверяет конфигурацию, Auth-контракты, права, платежные адаптеры, контент, изоляцию хранилища, demo и пакет. `npm run test:db` поднимает отдельный одноразовый PostgreSQL в Docker. `npm run test:integration:local` требует Docker и Supabase CLI: создаёт собственный локальный стек, проверяет настоящие Auth/REST/SQL и удаляет только созданные им ресурсы. Эти команды не используют облачный проект владельца.

`npm run doctor` выполняет только локальную проверку настроек. Код выхода 1 ожидаем в чистом шаблоне: ключей и юридических документов в нём нет.

`npm run package` создаёт ZIP и manifest в `dist/`. Архив не перезаписывается. `npm run verify:package -- dist/fitness-whitelabel-template.zip` проверяет пути, состав и SHA-256 каждого файла. Пакет не включает `.env.local`, базы, `content/live`, приватные медиа, зависимости или hosting bindings.

Для первого рабочего выпуска предусмотрен Docker за HTTPS-прокси. Статическая выгрузка на Vercel не заменяет сервер; этот путь не проверен.

Условия передачи учебного кода определяет автор курса. Данная инструкция не выдаёт лицензию и не меняет права на сторонние компоненты; см. `THIRD_PARTY_NOTICES.md`.
