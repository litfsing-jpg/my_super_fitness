# Бренд

В `brand.config.json` меняются название, короткое название, `accent`, `accentDark`, фон, собственный логотип из `assets/neutral` и поддержка. Это публичный файл. Ключи, токены и настройки магазина сюда не добавляются; сервер публикует только разрешённые поля.

Общий frontend сохраняет сетку и типографику исходной платформы: экраны «Сегодня», «Тренировки», «Питание», «Прогресс», «Ещё», мобильные safe areas, стеклянные поверхности и компактные действия. Конфигурируемые акценты передаются в CSS variables, включая `--fit-accent`. Геометрию и состояния меняй в `client/fitness-shell.css`, базовые элементы в `client/app.css`.

Google Sans подключён для рабочей версии через Google Fonts. Локальная offline-demo использует системный fallback и не запрашивает шрифты извне. Для полностью автономного выпуска добавь разрешённый локальный шрифт и его лицензию, обновив CSP и правила упаковки.

Логотип и нейтральные изображения можно заменить собственными файлами в своей установке. Не включай клиентские фотографии в общий пакет для других учеников. Правила упаковщика перечисляют публичные demo-assets явно; для нового общего ресурса расширь policy и проверь происхождение файла.
