# Передача Ученику Или Агенту

Это самостоятельный source-template, версия 0.1.0. Соседние проекты не нужны для запуска. Рабочие PrimeBody и «Система» не изменялись и не подключались.

## Первый Запуск

Из корня распакованного пакета:

```sh
npm ci
npm run demo
```

Открой http://127.0.0.1:4211. Демо использует вымышленные аккаунты и память собственного процесса; его серверные записи исчезают после остановки. Это не способ хранить данные участников. Параметр `?demo_owner=two` показывает отдельного вымышленного владельца. URL рабочего сервера не может включить demo.

## Задание Новому Агенту

> Работай только в этой директории. Сначала прочитай AGENTS.md, README.md и docs/SETUP.md. Разверни собственную установку из шаблона в режиме web, telegram или hybrid. Не используй подключения, контент, участников и платежные настройки автора. Сохрани UUID-владение, RLS, явную привязку аккаунтов и разделение YooKassa/RUB и Stars/XTR. Начни с локального demo и doctor; публикацию, облачные миграции, регистрацию webhook и реальные оплаты согласуй отдельно.

## Что Настраивает Владелец

1. Свой бренд и поддержку в `brand.config.json`.
2. Новый Supabase с миграциями `001`–`008`, SMTP и адресами возврата Auth.
3. Собственные документы и актуальные версии согласий в файлах и базе. Пока документы не готовы, платный контент закрыт.
4. Свой каталог и приватные медиа. В комплекте только 2 рецепта, 3 упражнения с демонстрационными MP4 и одна примерная программа.
5. Свои цены, магазин YooKassa, Telegram-бот и Stars, если выбран соответствующий режим. Сначала тестовая среда, без автосписаний.
6. HTTPS-домен, Docker/Node, резервное копирование и контроль очереди сверки оплат.

Инструкции: SETUP, AUTH, BRANDING, CONTENT, PAYMENTS, BACKUP. Ограничения: LIMITATIONS. Результаты проверок: ACCEPTANCE. История решений: IMPLEMENTATION.

Архив собирается allowlist-политикой; `.env.local`, базы, live-контент, приватные загрузки, зависимости и hosting bindings в него не входят. ZIP и manifest проверяются `npm run verify:package -- <archive.zip>`. После изменения кода создавай новый архив, не перезаписывай уже переданный.

Перед запуском с участниками обязательны тесты собственного SMTP, бота и тестового магазина, физические iPhone/Android, юридические документы, чеки и проверка восстановления резервной копии. Эти проверки не заменяются локальным demo.
