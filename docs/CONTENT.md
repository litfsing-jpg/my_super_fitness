# Свои Материалы

Production читает только `content/live/*.json`. Отсутствующий каталог показывает ошибку с повтором, а не чужую базу. Схемы примеров находятся в `content/examples`; полноценные нейтральные примеры в `content/demo`.

Каталоги: `exercises`, `band-exercises`, `foods`, `dishes`, `videos`, `stretching`, `ready-programs`, `recipe-visuals`. ID уникальны, максимум 120 символов: буквы, цифры, `_` и `-`. JSON не должен содержать HTML, JavaScript, внешние URL или ссылки на инфраструктуру автора. Каталоги выдаются только авторизованным участникам с подпиской.

В `foods` обязательны `id`, `name`, `portion` (например, `100 г`) и неотрицательные числовые `kcal`, `p`, `f`, `c` на указанную порцию. Не оставляй порцию пустой: она нужна и отображению, и пересчёту дневника.

Для упражнения обязательны ID, имя, `datasetVersion: "whitelabel-v1"`, мышцы, оборудование, уровень, шаги и `videoSrc`. Упражнения без видео не участвуют в подборе. Пример программы требует три совместимых упражнения; двух примеров рецептов недостаточно для разнообразного меню на неделю. Собственный рацион надо заполнить полноценной базой и проверить КБЖУ.

Видео и фотографии владельца положи в `content/media`, не в публичную папку. Имена без вложенности, например `squat.mp4`, `salad.webp`. Ссылки в каталогах: `/api/media/squat.mp4`. Приватные файлы выдаются по короткому opaque ticket, без JWT в URL; Range работает через тот же Node gateway. Не подключай отдельный static-сервер к этой директории.

`assets/neutral` предназначен только для явно публичных демонстрационных ресурсов и логотипа. MP4 в нём являются четырёхсекундными иллюстрациями интерфейса. Исходник HyperFrames и `scripts/build-demo-media.mjs` приложены; повторная сборка требует FFmpeg, Node и доступа к npm/CDN. Не выдавай эти файлы за уроки тренера.

В `recipe-visuals` визуал связывается с блюдом через `sourceId`. Atlas описывается количеством колонок/строк, индексами cover, ингредиентов и иллюстраций шагов. Реальные ингредиенты и КБЖУ берутся из `dishes`, визуальная анимация не меняет дневник. Для простых напитков используй содержимое и стакан, не выдуманные горизонтальные ломтики напитка.

В нейтральных атласах сетка 2×3. Кесадилья: готовое блюдо, лепёшка, начинка, сыр, продукты, финал. Крамбл: готовое блюдо, форма, фрукты, крошка, продукты, финал. Это собственная AI-графика, не кадры стороннего приложения. Генерация и происхождение записаны в `ASSETS.md`.

После импорта проверь фактическое декодирование видео, полные края посуды, состав и КБЖУ, аллергены, время приготовления и мобильные экраны. URL авторских Kinescope и сторонние домены намеренно не включены: для них нужен отдельный проверенный адаптер и CSP, не снятие всех ограничений.
