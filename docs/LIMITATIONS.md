# Границы Первого Пакета

Шаблон не подключён к рабочим сервисам автора и не опубликован. Для каждого ученика обязательны собственные Supabase/SMTP, домен, документы, бот и магазин. Чистая установка закрыта до настройки.

AI-куратор, Apple Health, камера с анализом техники, Telegram-клуб и дополнительные образовательные интеграции скрыты, пока не реализован и не проверен отдельный адаптер владельца. Самостоятельный необратимый сброс прогресса также скрыт до отдельного проверенного server-adapter; аккаунт и история сохраняются. Код применимых модулей сохранён; не включай кнопки без соответствующего backend и политики данных. Массовые рассылки, retention-офферы и автоматическое удаление участников не переносились.

Два рецепта и три демонстрационных упражнения нужны для показа интерфейса. Это не готовая большая библиотека, программа тренера или медицинская рекомендация. Полноценное недельное меню требует собственного достаточно разнообразного каталога и проверки целей КБЖУ. Фото человека не оценивается как точное измерение процента жира.

Основной deployment: Docker/Node за HTTPS reverse proxy. Multi-instance gateway, распределённые media tickets и распределённый rate limiter пока не реализованы: первая версия рассчитана на один процесс. После перезапуска краткоживущую media-ссылку нужно запросить снова. Vercel server adapter не проверен.

Фискальные чеки, правовые условия, возвраты спорных оплат, SMTP deliverability, реальная тестовая покупка и испытания на физических iPhone/Android остаются ответственностью владельца перед live. Проверка браузерных размеров и синтетического Telegram-контракта не заменяет испытание его бота на устройстве.

Зависимости закреплены lockfile. До публичного запуска проверь npm audit и применимые обновления в своей ветке с регрессией. Используемые generic-модули сохраняют прежние внутренние названия ключей для совместимости; внешние подключения и права задаются только этой установкой.
