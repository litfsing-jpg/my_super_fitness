# Приёмка 0.1.0

Дата: 26 октября 2026. Область: локальный передаваемый шаблон, не публикация готового клиентского сервиса.

## Выполнено

- `npm test`: 43/43. Конфигурация, закрытый gateway, Auth/linking, RLS-контракты, платежи, бот, admin, media tickets, изоляция Storage, cleanup, Telegram launch, вода, подходы, КБЖУ и упаковка.
- `npm run test:db`: реальные assertions на одноразовом PostgreSQL 17. Чужие данные закрыты; истечение не удаляет прогресс; нет self-elevation; grant идемпотентен; nonce одноразовый; текущие согласия обязательны; возврат до success не выдаёт доступ; proof RPC ограничен владельцем.
- `npm run test:integration:local`: настоящий изолированный Supabase Auth/REST/PostgreSQL/Storage. Email/password, Telegram HMAC → настоящая Auth-сессия, конкурентный первый вход, refresh, явная привязка к одному UUID. HTTP → SQL оплаты проверены с fake-провайдерами: неверная сумма и чужой заказ отвергаются, повторы не продлевают дважды, RUB и XTR раздельны.
- Настоящая Storage HTTP-загрузка → proof RPC → чтение. Повтор возвращает тот же receipt; чужое чтение, overwrite, удаление отправленного подтверждения и доступ после смены версии согласий закрыты.
- Независимое security-review и повторные проверки: блокирующих замечаний не осталось. Исправлены init бота, порядок возвратов, Stars reconciliation, справедливость worker, DB legal gate, приватная очистка при выходе, маршрутизация proof UI и выход в соседних вкладках. Для исправлений добавлены регрессии.
- Docker image собран; запущен без сети и с непривилегированным пользователем. Внутренний HTTP smoke: health/локальный SDK доступны, закрытый API 503, env/server files 404, preview URL не открывает платформу. Тестовый контейнер остановлен.
- `npm audit --omit=dev`: 0 найденных уязвимостей на момент проверки; зависимости закреплены lockfile.
- Браузер: анкета, создание своей тренировки, видео 960×540 с readyState 4, запись и редактирование подхода, переход назад, пауза/продолжение. Добавление еды и воды, избранное, оба анимированных рецепта, каталог, возврат, прогресс. После reload сохраняются дневник и подходы; второй demo-owner не получает первую анкету.
- Размеры 320/360/390/430 px и desktop 1280 px: горизонтального переполнения страницы нет; шапка остаётся на месте. Сохранены локальные контрольные скриншоты вне передаваемого пакета. Старые ошибки startup/порции исправлены; после исправлений новые ошибки консоли в пройденных сценариях не появились.
- Упаковщик отклоняет секретоподобные значения и symlink, исключает локальные env/привязки/контент, не перезаписывает архив; verifier сверяет пути, размеры и SHA-256 payload.

## Не Проверено На Реальных Сервисах

Боевой SMTP и восстановление email в почтовом приложении, реальный бот/WebView Telegram с заблокированными cookies, invoice UI и покупка/возврат у живого провайдера, касса, юридическая применимость, физическая клавиатура и safe areas iPhone/Android, Vercel и multi-instance. Контрактные Telegram-тесты и браузерные ширины не заменяют эти проверки.

Production по умолчанию закрыт. Чистый `doctor` ожидаемо возвращает код 1 с перечнем отсутствующих собственных настроек и документов; это не тестовый сбой и не разрешение включить платный доступ. Запуск с участниками разрешён только после собственной настройки и этих проверок владельцем.
